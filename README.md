# App: Minecraft Memory Card Game

[Design inspiration](https://alex-dishen.github.io/memory-card/)

# Features

- Loading Screen 🟩
  - Credit tool tip 🟩
- Gamemode Screen 🟩
  - logo 🟩
  - easy, medium, hard button 🟩
- Gameplay Screen 🟩
  - logo (exit game) 🟩
  - cards 🟩
  - scoreboard 🟩
- Cards (10)
  - load
  - randomize
  - click (flip and evaluate)
- Scoreboard 🟩
  - Current Score 🟩
  - Best Score 🟩
- Dialog
  - Win dialog
  - Lost Dialog
  - Restart button
- Help button
- Sounds and Music
  - Sound button
